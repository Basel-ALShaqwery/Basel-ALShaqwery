## 🚀 Featured Projects

### 📊 Bus Operations Machine Learning Project
**DECI | Data Science & AI**

An end-to-end machine learning project analyzing bus operations and predicting delays and trip duration.

- Processed 10,000 raw records into 9,850 cleaned records.
- Built classification models for On Time, Moderate Delay, and Severe Delay.
- Developed regression models to predict trip duration.
- Used leakage-safe preprocessing pipelines and stratified train/test splitting.
- Evaluated models with five-fold cross-validation.
- Compared classification performance using Macro F1 and regression performance using R², MAE, and RMSE.
- Saved trained pipelines with Joblib and generated predictions for unseen trips.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Joblib.

🔗 [View Repository](https://github.com/Basel-ALShaqwery/bus-operations-machine-learning-project)
